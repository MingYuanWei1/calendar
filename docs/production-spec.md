# 学校公共校历：成品版

本规格承接用户“按这个继续做成品”的指示，替代静态阶段“不做后端、不持久化”的交付限制。沿用已确认的 C 方案、学部／类型筛选、无小日历，以及学生和管理员的全部交互。

## 本轮完成标准

- 学生无需登录，查看已发布及已取消的事件；服务器不得向匿名请求返回草稿。
- 管理员经过真实登录才能创建、编辑、发布、取消或删除事件；服务端逐次验证权限。
- 事件与管理员会话持久化；刷新或服务重启不丢失保存的事件。保留改期前的时间及服务器更新时间。
- 中英字段、适用范围、类型、四种时间形式在客户端和服务端校验；并行安排允许重叠。
- 海报与二维码支持实际图片；外部报名链接可编辑；没有平台内报名功能。
- 今天与默认月份使用学校时区下的真实日期，学校名称和时区可配置。
- 正式入口固定为已选 C 方案；旧设计评审保留在 designs 目录，不混入正式操作流程。
- 保存中、防重复提交、请求失败、登录失效均有可见反馈；失败不清空已输入内容。
- 提供运行、初始化管理员、数据备份与部署说明；不提交密码、会话或数据库文件。

## 仍然不做

个人课程、报名记录、审核、通知、重复事件规则、自动节假日、自动翻译与学校 SSO 集成（除非用户在本轮指定）。

## 交付与验收

延续浏览器公开交互验收；为新增的登录和持久化接口补充真实 HTTP 集成验证，重点检查未授权写入、草稿隔离、服务端校验和重启后数据保留，不测试私有函数实现。

用户尚未指定部署平台与其他登录方案，按已说明的默认方式交付：本地 Node 服务、SQLite 持久化、单管理员账号。保留部署配置，不创建外部服务或上线公网。
