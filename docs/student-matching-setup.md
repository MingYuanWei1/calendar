# 学生匹配启用说明

学生身份、自动勾选和座位提醒已实现，对应 [规格 #8](https://github.com/MingYuanWei1/calendar/issues/8) 与实施任务 #9–#15。

## 管理员启用

1. 在「考试管理 → 学生管理」填写学校实际邮箱域名，不包含 `@`。示例域名不会自动启用。
2. 检查考试批次所属学年：填写开始年份，例如 `2026` 表示 2026–2027 学年。毕业年份按 `学年开始年份 + 1 + 12 − 年级` 计算；该学年十年级学生对应 2029 届。暑期、历史批次以明确的所属学年为准。
3. 手工录入、Excel 或 LLM 导入座位。Excel 新模板允许填写 1–12 年级；旧七列表格仍可使用。`10.5` 等可识别班级格式或单年级场次可提供年级，缺失和矛盾应由管理员修正。
4. 在导入预览中核对姓名、拼音、毕业年份、邮箱与冲突。编辑姓名、班级或年级后点击「重新核对身份」，再确认替换草稿并保存。
5. 在学生管理核实同音姓名、拼音和邮箱。必要时填写实际学校邮箱；确认重复记录后先预览合并，再合并。学生使用稳定内部编号，修正邮箱不会换号。
6. 保存并发布座位。学生信息修正只影响之后发布的版本；旧批次需重新保存草稿、核对并重新发布。未解决的身份冲突跳过自动匹配，不阻止其他学生正常使用。

## 登录与个人考试

Microsoft 登录现在请求 `openid profile email`，仅使用已校验 ID token 的 `email` 字段，账号标识仍为租户与用户对象 ID。已有登录会话需退出后重新登录才能取得邮箱。缺少邮箱、学校域名不符或前缀不满足两位年份加英文字母时，跳过自动同步，仍可手动使用。

每个账号、每个批次在首次取得可匹配的已发布座位时自动追加关联考试，保留已有选择。之后自由更改，包括全部取消，不会被再次登录覆盖。

后续新增关联考试弹出「有新的关联考试」，可一键导入、选择考试导入或取消。本次处理过的场次不重复弹窗，也可随时通过「导入关联考试」重新选择。

考试详情默认显示本人考场并高亮本人座位，其他考场仍可查看。当前已选考试的座位新增、移动、删除或暂时撤下会合并提醒；删除座位不会取消考试选择。草稿编辑不触发提醒。页面进入、切换批次、回到前台及持续打开每分钟检查更新。
