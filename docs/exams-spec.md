# 考试安排

确认于 2026-09-20。独立考试入口沿用校历风格，按批次、学部、年级浏览，考试可跨周，批次保留历史。每场独立起止时间、课程/级别及多个教室。不同学部不混合显示。

学生身份匹配、首次自动勾选及后续提醒扩展见 [学生匹配规格](student-exam-matching-spec.md)。学校组织内 Microsoft SSO 用户可以查看所有已发布座位表；逐场自行勾选（支持批量），按账号保存。我的考试展示当前批次全部已选场次，不受学部/年级限制，不依赖座位发布。修改保留场次 ID 与选择；取消保留记录并标注，时间冲突提示但不阻止。

每场重新安排座位，支持同一教室混考。排从讲台向后、列从左向右，教室排列可配置。标准 Excel 每行：考试编号、教室、排、列、班级、中文名、英文名；班级必填，姓名至少一种，无学号、邮箱、独立座位号。导入预览、校验、再确认并支持网页编辑。同一教室同一时段有多场考试、座位表又没写明学生考哪一场时，座位不丢弃，标为“待定”（如 Chinese B / Honor）：学生关注其中任一场都能看到该座位，但不会自动加入“我的考试”；管理员可在座位编辑中改为具体考试。

考试安排和座位表独立草稿、预览、发布；修改后再次发布。PDF 仅导出整个批次的 schedule，范围可为所选学部/年级或我的考试，不含学生和座位信息，注明生成时间及取消/变更。管理员使用现有管理员登录；SSO 不自动授予编辑权限。

更新于 2026-10-11：座位表导入默认合并进草稿，导入前列出新增与修正（修正前 → 修正后），可改为替换全部。座位表与考试安排的 AI 提取为后台提取任务，关闭页面后继续运行，见 [ADR 0001](adr/0001-background-extraction-jobs.md)。学生管理并入管理后台（`console.html#students`），仅系统管理员（role 3）可见与调用，支持搜索、按班级/届别/有问题筛选和分页；旧地址 `/students` 跳转到此。
