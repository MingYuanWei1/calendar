# 三套视觉方向

## 已选方向与修订

追加修订：移除 C 方案侧栏的小月历及其月份／学期标题，侧栏直接从学部筛选开始。

用户选择 C「轻盈分区」，并要求增加左侧栏。电脑端采用“左侧筛选＋月历＋右侧详情”：学部筛选和 A 方案的五类事件复选框统一放在左栏，顶部不再重复。保留 C 的色彩、圆角和表面层次。手机保留列表上方的紧凑筛选。评审页默认打开修订后的 C 方案；下文记录初轮方案以便对照。

## 共同约束

学生查阅公共事件；电脑月历为主，点击事件在右侧阅读详情。左上角 LOGO 占位。中文默认、英文切换。所有事件均为虚构示例，2026 年 9 月的日期与星期按公历计算；演示中的“今天”固定为访谈日期 2026-09-19。

三套方案采用同一组数据与类型颜色语义，不增加统计卡片、个人任务、报名管理等需求外功能。以同一示例“校园艺术节”展示详情，以跨日考试、截止日、取消、改期及密集事件检验设计。

## A 经典日历

- 色彩：纸白 #FFFFFF，浅灰 #F8FAFD，墨灰 #202124，辅助灰 #5F6368，日历蓝 #1967D2，分隔线 #DADCE0。
- 字体：Arial / PingFang SC 用于正文，月份使用较轻字重，日期用等宽数字。
- 布局：左侧小月历与筛选，中部七列月历，右侧细节面板。
- 特征：熟悉的蓝色当天圆点、紧凑事件条，优先提高密集信息的扫描效率。

```text
LOGO 校历     日期导航                        搜索 / 语言
筛选侧栏      月历                            事件详情
```

## B 校园公告

- 色彩：暖白 #FAF9F5，纸白 #FFFFFF，深绿 #254E43，墨色 #26342E，辅助灰 #65726A，分隔线 #DEDFD7。
- 字体：Songti SC / Georgia 仅用于学校标题和月份；正文 PingFang SC / Arial。
- 布局：顶部学校刊头，下一行大月份与筛选；移除常驻左栏，月历获得更宽空间；右侧详情像公告正文。
- 特征：月份的文字层级和适度留白带来校园公告感，事件仍保持结构化，不用装饰插画占据日历空间。

```text
LOGO 校园日历                                语言
九月 · 2026       搜索 / 学部 / 类型 / 视图
宽月历                                      公告详情
```

## C 轻盈分区

- 色彩：冷灰 #F1F5F8，纸白 #FFFFFF，墨蓝 #243746，湖蓝 #28647B，浅蓝 #E4EFF4，分隔线 #D9E3E9。
- 字体：Avenir Next / PingFang SC 用于标题，系统无衬线字体用于正文和辅助信息。
- 布局：紧凑顶部品牌导航，学部筛选横向呈现；月历和详情作为两个明确表面，类型筛选位于月历上方。
- 特征：适用范围比经典方案更突出，轻圆角与冷色留白强化内容分区。

```text
LOGO 校历                        搜索 / 语言
全部学部  小学部  初中部  高中部
月份 / 类型 / 视图                  事件详情
月历白色表面                         详情白色表面
```

## 已完成的设计自检

三套方案不只换色：A 常驻左栏，B 宽幅公告式布局，C 横向学部导航与独立详情表面。保留同样的数据和功能，避免把功能差异误当成审美选择。小屏切为列表，长标题在详情中完整显示，类型同时使用文字与颜色。

## 页面扩展计划

用户选定视觉方向后制作：筛选和空结果、当天全部事件、日程列表、手机列表与详情、后台事件列表、新增／编辑、草稿／预览／发布、取消与改期状态。当前方向稿提供部分可操作演示以帮助判断布局，不提供登录或持久化数据。
