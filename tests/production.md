# 成品版验收

日期：2026-09-19。正式代码位于 public/ 与 server/；验收使用独立 .scratch/browser-test 数据目录，不把测试事件写入交付数据库。

## 自动集成验证

运行 `npm test`，真实监听本地 HTTP 端口并通过 fetch 请求接口。

- 错误密码、匿名写入、跨站请求被拒绝；会话 Cookie 为 HttpOnly。
- 草稿不进入公开事件接口；重新启动应用后仍能从管理接口读取。
- 不存在日期、无时刻截止日、非法外部链接、全校与学部混选被服务端拒绝。
- 发布、版本冲突、改期原时间、取消原因、删除和退出登录。
- PNG 上传重新编码 WebP；不合法图片和匿名上传被拒绝。
- 隐藏数据目录中的图片可正确读取；草稿图片匿名不可访问，发布后可访问，删除引用事件后再次不可访问。
- 环境文件不由静态路由公开；返回基本安全响应头。
- 受信反向代理按真实客户端限速；未配置受信代理时忽略伪造转发头。
- 完整 HTTP 套件 3 项通过（包含多项接口断言）。

## 浏览器验收

内置浏览器操作 http://127.0.0.1:3001/，使用专用测试账号。

- 实际账号密码登录；错误密码有提示。
- 新增双语事件→保存草稿→刷新→重新进入管理列表，草稿仍在。
- 从本机选择 PNG 二维码并上传→预览→发布→公开详情读取实际图片。
- 重启服务后事件与图片仍可查看。
- 390×844 手机全屏详情，日期、报名链接与二维码可读，无横向溢出。
- 第二个窗口退出登录使第一个窗口会话失效；保存失败后保留输入，通过弹窗重新登录即可继续保存。
- 真实改期后公开详情显示原时间与现时间；取消后保留记录及原因。
- 停止验收服务制造连接失败：取消弹窗保留原因和重试按钮；刷新管理列表显示失败提示，保留登录态，不误跳登录页。

## 运维

`npm run typecheck` 检查正式前端与历史设计稿；服务端由语法检查与 HTTP 集成场景验证。

备份脚本已在独立验收数据目录运行，生成数据库快照与媒体副本。Docker 配置与 HTTPS 部署说明已提供，但本机未进行 Docker 或公网部署验收。

## 双轴审查

以 `5513f3e` 静态定稿为基准。Standards 审查提出 1 项代理限速正确性问题；Spec 审查提出 2 项请求失败处理问题。均修复并通过针对性回归，复审无遗留问题。

## 紧凑月历布局修订

- 月份、上／下月、今天和视图切换移至 header；删除介绍标语。
- 在 1237×788 与 884×788 电脑窗口检查：整页高度等于窗口高度，最后一周及页脚无需向下滚动；另检查 2026 年 11 月六周网格。
- 日历根据每周可用高度调整可见事件条数，9 月 23 日展开仍为 6 项；详情和日程采用区域内滚动。
- 390×844 手机英文布局检查通过，月份与导航位于 header，日程及筛选保持可用。

## 日期安排与节假日区分

- 工作日白底、普通周末浅灰底、管理员指定放假日浅绿底＋「休」、调休上课日白底＋「上课」。顶部日期名称及底部图例中英切换。
- 日期安排单独持久化，范围应用于全校，不随学部、类型或事件搜索筛选变化；不自动推断法定假期。
- 样本：2026-09-20 调休上课，2026-09-25 至 27 秋季休假，均注明示例。
- 新增 HTTP 场景验证匿名写入拒绝、非法范围拒绝、批量设置／覆盖与恢复默认；完整 4 项集成场景通过。
- 浏览器在独立测试数据下通过后台「放假与调休」按范围保存；正式站点确认底色、标签及整月布局，排除假期事件后保留放假标识。

- 月历密度修复：跨日条只占用实际覆盖的日期；单日事件填入该日空闲行，仅真实溢出时预留“还有 N 项”。884×788 浏览器复验 9 月 18、19、20 日直接显示事件，26–27 日跨日假期不再无故折叠，23 日展开仍有 6 项。
