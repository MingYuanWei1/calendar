# 成品版验收

日期：2026-09-19。正式代码位于 public/ 与 server/；验收使用独立 .scratch/browser-test 数据目录，不把测试事件写入交付数据库。

## 自动集成验证

运行 `npm test`，真实监听本地 HTTP 端口并通过 fetch 请求接口。

- 错误密码、匿名写入、跨站请求被拒绝；会话 Cookie 为 HttpOnly。
- 草稿不进入公开事件接口；重新启动应用后仍能从管理接口读取。
- 不存在日期、无时刻截止日、非法外部链接、全校与学部混选被服务端拒绝。
- 发布、版本冲突、改期原时间、取消原因、删除和退出登录。
- PNG 上传重新编码 WebP；不合法图片和匿名上传被拒绝。
- 隐藏数据目录中的图片可正确读取；草稿图片匿名不可访问，发布后可访问，删除引用事件后再次不可访问。
- 环境文件不由静态路由公开；返回基本安全响应头。

## 浏览器验收

内置浏览器操作 http://127.0.0.1:3001/，使用专用测试账号。

- 实际账号密码登录；错误密码有提示。
- 新增双语事件→保存草稿→刷新→重新进入管理列表，草稿仍在。
- 从本机选择 PNG 二维码并上传→预览→发布→公开详情读取实际图片。
- 重启服务后事件与图片仍可查看。
- 390×844 手机全屏详情，日期、报名链接与二维码可读，无横向溢出。
- 第二个窗口退出登录使第一个窗口会话失效；保存失败后保留输入，通过弹窗重新登录即可继续保存。

## 运维

`npm run typecheck` 检查正式前端与历史设计稿；服务端由语法检查与 HTTP 集成场景验证。

备份脚本已在独立验收数据目录运行，生成数据库快照与媒体副本。Docker 配置与 HTTPS 部署说明已提供，但本机未进行 Docker 或公网部署验收。
