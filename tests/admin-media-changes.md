# 媒体与状态变更（浏览器公开界面）

首次红灯：新增页没有海报、二维码设置；管理列表没有取消、删除操作。

1. 编辑页选海报、示例二维码、填写 HTTPS 链接；预览和发布详情包含相同内容。
2. 单链接、单二维码、组合、全空均可表达；无入口不显示空区块。海报可放大和键盘关闭。
3. 选择损坏图片示例，出现替代说明，其他详情仍可使用。二维码编码 example.org 的演示地址。
4. 拒绝非 HTTP(S) 报名 URL；不向外部提交信息。
5. 发布后修改时间，原定时间与现定时间均在详情展示；原日期不再显示该事件。
6. 取消确认说明将保留公共记录；提供取消原因后公开详情可见，报名入口关闭。
7. 删除确认明确从公共校历与管理列表移除；返回不删除，确认后消失。
